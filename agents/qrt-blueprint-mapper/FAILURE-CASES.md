# Failure cases learned from real QRT-D1 qualification — not theoretical style advice

Each example is a **test the agent must perform** on the *current item*. These cases originated in issue #200's source-specific draft PRs. The recorded original failure does **not** imply every future question has it.

| Failure class and real example | Why the early approach was insufficient | Required agent behavior |
| --- | --- | --- |
| **Starting from blueprints instead of the question** | A set of five plausible-looking Core pages can hide a misclassified task or an unprotected W. | Solve original question and formally challenge primary demand/band **before** choosing registered roles or copying a teaching route. |
| **MODEL-D1 original H2 leak** ([#204](https://github.com/reallakshman19/Grade9v3.5/pull/204)) | H2 guided the student toward a separate group for every tray before model selection; H3 still correctly locked, giving false confidence. | Inspect each opt-in H1/H2 for the protected decision (grouping/model relation) independently of H3 gating. Repair question-specific H2, not registry. |
| **RETRIEVE-D1 original H2 leak** ([#212](https://github.com/reallakshman19/Grade9v3.5/pull/212)) | A hint printed exact prime/composite/neither divisor thresholds while the skill was to *retrieve that criterion*. | A hint may ask the learner to recall the rule but must not supply its critical definition. Validate old text absent from actual HTML, not only source. |
| **SYNTHESIZE-D1 leading H2** ([#213](https://github.com/reallakshman19/Grade9v3.5/pull/213)) | “Are both component kinds copied each time?” handed over the disputed whole-unit dependency as a yes/no cue. | Use a neutral expression-check prompt; make the student choose coverage/ordering. Leave SYNTHESIZE-vs-MODEL/APPLY classification open pending academic challenge. |
| **SYNTHESIZE mathematical equivalent route** ([#213](https://github.com/reallakshman19/Grade9v3.5/pull/213)) | “Unit first is the only correct order” would reject valid distributed form `4×3+4×2=20` versus `4×(3+2)=20`. | Derive accepted equivalent methods before writing prompts, rubric, transfer or source answer. Don't assert automatic grading if page merely gates/reveals solutions. |
| **JUSTIFY-D1 missing five-role projection** ([#206](https://github.com/reallakshman19/Grade9v3.5/pull/206)) | A mathematically sound original-practice candidate existed, but it wasn't a five-role native suite; pretending it was “admitted” would invent source rights. | Reuse existing eligible authored source with explicit provenance. Build missing roles if needed, exclude `CORE2` without authentic custody; source and QRT acceptance remain distinct. |
| **JUSTIFY-D1 ambiguous perpendicular height** ([#206](https://github.com/reallakshman19/Grade9v3.5/pull/206)) | “Distance to line AB” depended on visual understanding; source SVG long `<desc>` did not survive as a native accessible label. | State 90° shortest distance to the **extended** baseline in text, check resulting native `aria-label`, and keep human comprehension hold open until QA signs off. |
| **JUSTIFY-D1 answer 42 alone** | Correct numerical equality can coexist with missing *warrant*. A nonblank attempt is not an academic correctness check. | Require mathematical reason `A=bh/2` with equal bases and perpendicular heights (or equivalent determinant/shear proof); provide human-review cases for numeric-only partial answers. |
| **Core1A staged SVG duplication** ([#206](https://github.com/reallakshman19/Grade9v3.5/pull/206)) | The native renderer reveals stage groups **cumulatively**, so drawing a whole triangle in each stage overlaid lines/labels at stage 3 even when all role slots rendered. | Build base geometry in stage 1, incremental numeric annotations in later groups. Inspect all stages in a browser and regression-test no duplicated geometry. |
| **14px label floor at scale** ([#206](https://github.com/reallakshman19/Grade9v3.5/pull/206)) | SVG font-size looked large in a 760-unit viewBox but scaled to <14px on actual page. | Measure on-screen rendered font and reposition/scale source figure, not weaken the global text floor. |
| **Receipt checked only five roles** | A supplementary evidence record omitted `index.html`, though the renderer's original receipt did include it. | Count *actual emitted pages*, independently hash five role files **and index**, compare complete SHA map to `render-receipt.json`. Don't propagate the incorrect claim that the renderer lacked index. |
| **Confusing golden byte parity with semantic compatibility** | Different source questions necessarily render different HTML. A frozen original's digest is meaningful only for that original/pinned revision. | Keep Owner lock immutable; check T01–T15 transfer of pedagogical techniques across source questions and reserved byte checks only for same-source cases. |
| **Duplicating review viewer / exposing confidential Q003** | The 28-cell Q003 matrix already exists on a separate branch, and Q003 original source may be private. | Link source-safe evidence tiles into the existing viewer when authorized; never duplicate it or copy private source bytes into generic demo files. |
| **“Main red too” ≠ zero regression** | Repository assurance, guardrails, regression delta were already failing on main, but same failing category does not prove identical findings. | Compare **exact** test/finding IDs on same toolchain; leave unrelated global debts outside scoped PR unless specifically authorized. |
| **Treating research peer waiver as QRT approval** | A waiver for the original research seed did not resolve question-quality hold or per-cell QRT Owner acceptance. | Require the applicable QRT-specific waiver or qualified review and a recorded Owner cell decision ID. Academic accepted remains zero until such evidence exists. |
| **Test assertion demanded literal internal JSON answer in learner HTML** | The native renderer may project a reasoning move without dumping `acceptable_alternatives` verbatim. | Assert the source-level answer contract *at source level* and actual learner page exposure/behavior *at HTML level*. Do not alter renderer to satisfy a mistaken assertion. |

## The four questions to ask whenever a blueprint seems “missing”

1. Is this actually a **source problem** (incorrect wording, figure or metadata, inadequate worked example, over-leading H2, inaccessible label, wrong answer alternatives)?
2. Is this actually a **QRT classification problem** (protected W too small, mistaken primary verb, adjacent band ambiguity, multiple valid solution routes)?
3. Does the existing blueprint/renderer **already express the required pedagogical technique** with correct source and roles?
4. What *exact source-correct HTML behavior* demonstrably fails—page ID, input SHA, blueprint ID, expected-vs-actual and reproducible viewport/interaction—if a genuine global gap remains?

Only after answering all four with evidence should a change to shared blueprint or renderer be proposed. A “new agent” should not automatically manufacture a new blueprint whenever it sees a new question.
