This is a manually selected repository agent profile at `.github/agents/qrt-blueprint-mapper.agent.md`. Once the change is integrated into a branch supported by your Copilot environment, choose **qrt-blueprint-mapper** and supply a question ID/source path. Agent availability depends on your Copilot configuration.

## Suggested invocation

> Map question <ID> to its correct QRT primary demand and band. Independently solve it, identify X/Y/Z/protected W, and challenge adjacent demands. Reuse current registered Core blueprints, distinct worked/error/transfer roles and the frozen golden's techniques. Do not build a new blueprint. Render actual HTML and SHA six pages only if authorized; otherwise return a review-only evidence card. Leave academic and Owner approvals pending.

## Five live trials

1. **MODEL:** Six trays with four seedlings — old H2 directed group choice. Test whether new agent spots this before making a page and preserves actual protected W.
2. **RETRIEVE:** Full divisor list {1,5,25} — old H2 supplied the prime/composite threshold. Test whether preattempt criteria remain learner-owned.
3. **SYNTHESIZE:** Four two-part motifs {3 blue,2 red}; accept both `4(3+2)` and `4×3+4×2`. Test whether model comparison and D1-vs-D2 uncertainty remain explicit.
4. **JUSTIFY:** Triangles share base 12 and perpendicular height 7; number `42 cm²` alone is not a proof. Test source wording, accessibility, equivalent proofs and still-open learner-quality hold.
5. **Unseen item:** Provide an original eligible question from a different topic. Test whether the agent discovers the registry, schema and golden anew rather than copying prior examples.

## Eight required evaluation questions

Does the agent (1) verify provenance/rights, (2) independently solve mathematics and classify QRT, (3) preserve a nontrivial W, (4) design truly different Core1A/Core1B/Core2B decisions, (5) check H1/H2/H3 and all accessibility surfaces, (6) prove real registered-renderer HTML with six hashes/receipt and actual browser, (7) compare different-question goldens **semantically** while preserving immutable original locks, and (8) leave all qualified reviewer, Owner, rights and release decisions pending until real authorization?

A trial passes only when the answer to all eight is demonstrably yes. Static repository CI validates **agent configuration and blank evidence-card safeguards**, not model reasoning quality or actual agent deployment. Human evaluation must use fresh questions after agent-profile changes.
