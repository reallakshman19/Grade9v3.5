13 October 2026 · Grade9 #182 · Owner v3.1.0 label_sha 2ff9246 · parent source #183 for protected originals.

This is a **TEST-only source-safe authoring and review protocol** for issues #200–#203 and the existing [Q003 reference HTML](q003-model-d2/index.html), not a new learner-page blueprint, golden blessing, source licence, release or 28 automatic pass marks. Academic accepted 0/28 at baseline.

## Immutable layers (do not conflate)
1. **Canonical QRT identity:** one primary demand from RETRIEVE/EXPLAIN/APPLY/MODEL/REPRESENT/SYNTHESIZE/JUSTIFY and a justified D1–D4 band; source `Shared/quality/question-demand-matrix.v1.json`; its compiled 28 `question-demand-templates.v1.json`. QRT controls H/S/P/M semantics and learner-owned **W**, not page layout.
2. **Registered Core page blueprint:** `Shared/web/interactive-page-blueprints.v1.json` selects the applicable Core1, Core1A, Core1B, Core2, Core2A or Core2B page structure. Preserve reusable blueprint versions; a *change request* exists only for measured mismatch that authored records or projection implementation cannot express.
3. **Authoritative input:** original authored TEST package/manifest and original owned source bank when permitted. Only **authenticated source Core2** uses `selection.core2` from source bank; never pass authored Core2A as a source exam item. All original 68 intake and Q003 private custody governed by #183, no original text uploaded into tiles or Common.
4. **Renderer-native evidence:** `Shared/tools/render_core.py build --manifest <m> --out <dir> --mode PAGES --reference` produces actual learner HTML and receipt; five-role TEST packages yield five Core HTML + index. Record branch exact HEAD; source/manifest/registry/renderer blobs; per-page independently computed SHA256, sizes, declared gaps, artifact URL/authorized private digest. Require zero depth gaps and no silent selection drop.
5. **Golden *comparator* identity:** `G-IMO-G9-FIVE-CORE-20261012` is Owner-designated exact HTML *for those five original TEST snapshots*, with immutable SHA lock; its **techniques**, not unrelated literal learner text/digests, are comparators for other questions. `G-IMO-CORE2-UI-R1` is the Owner-approved **source-safe authored HTML UI/interaction reference only**; `G-CORE2-R2` is **candidate Physics/JEE Core2** method; `G-MATH-LINEAR-CONSTRAINT` is **candidate math** teaching comparator. None of those accepts Q003 academic content or is interchangeable with an authentic source byte oracle.
6. **Reviewer evidence and Owner authority:** independent, qualified subject reviewer with author/fixer conflict statement judges maths, primary cognitive demand vs alternative, band via five difficulty components, X/Y/Z/W, all twelve H1–H3/S1–S3/P1–P3/M1–M3 objectives (not counts), real learner behavior, and a new changed-case solution. Owner independently records per-cell `ACCEPT/REVISE/REJECT` + unique ID and separately scope-designates versioned golden storage and public rights.
7. **QRT page:** `q003-model-d2/index.html` is the 7×4 *administrative* viewer. `q003-model-d2/band-issues.v1.json` lists all 28 cell IDs, old worker artifacts and new band issues. Make a source-safe tile per reviewed exemplar with exact roles, published artifact links/authorized private SHA, chosen comparator, reviewer status and Owner decision. The tile does not render or constitute an original Core learner page.

### Distinguish two kinds of golden tests
- **Snapshot regression:** original exact source, renderer, manifest and Owner snapshot should regenerate expected byte-identical HTML where reproducible. Run `build_golden.py --id G-IMO-G9-FIVE-CORE-20261012 --check` only as a zero-gap structural check; its pinned manifest may produce a distinct authority digest from the frozen original, so **do not mistake this for an exact snapshot-byte parity test**. Use the dedicated immutable lock test for frozen bytes.
- **Cross-question benchmark:** no raw cross-question equality. Report requirements and learner behavior in a role-specific matrix, annotated `MATCH / CONTEXTUAL_DIFFERENCE / DEFECT / JUSTIFIED_NA`. A differing number, diagram, cognitive task or QRT ID is expected; a preattempt answer leak or invalid check is a defect. A new golden **candidate** can be collected from already rendered source-safe TEST pages but becomes Owner-designated only with an explicit new fixture ID/bytes/version/rights decision. Never mutate either earlier golden.
