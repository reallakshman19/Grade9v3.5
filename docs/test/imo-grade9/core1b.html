Core 1B · Divisibility Proof Reconstruction

In Core 1A, you learned why n(n+1)(n+2) is always divisible by 6 for any positive integer n. In Core 1B, you must reconstruct the proof unassisted through two cognitive retrieval gates.

Stage 1 · Boundary Recall (Foundations)

Without checking reference tables, answer these three foundational recall prompts:

1.1 Parity Principle

Why is at least one of n and n+1 divisible by 2? Does this depend on whether n is prime or composite?

1.2 Modulo 3 Residue Classes

List all possible remainders when an arbitrary positive integer n is divided by 3, and state for each remainder which term among {n, n+1, n+2} is a multiple of 3.

1.3 Coprime Multiplicative Divisibility

If integer a divides N and integer b divides N, under what strict condition is N guaranteed to be divisible by a * b?

Stage 1 Recall Reference

  • Parity: Integers alternate between even and odd: n ≡ 0 (mod 2) or n ≡ 1 (mod 2). If n is odd, n+1 is even. Hence 2 | n(n+1) holds universally regardless of compositeness.
  • Residues mod 3:
    • If n ≡ 0 (mod 3), then 3 | n.
    • If n ≡ 1 (mod 3), then n+2 ≡ 3 ≡ 0 (mod 3), so 3 | (n+2).
    • If n ≡ 2 (mod 3), then n+1 ≡ 3 ≡ 0 (mod 3), so 3 | (n+1).
  • Coprimality: a | N and b | N implies ab | N if and only if gcd(a, b) = 1. Since gcd(2, 3) = 1, 6 | N follows rigorously.

Stage 2 · Complete Step Reconstruction

Reconstruct the complete mathematical proof that n(n+1)(n+2) is divisible by 6 for all n ∈ ℤ⁺. Include the four standard verification moves: Declare, Transform Parity, Transform Modulo, and Coprime Synthesis.

Model Proof Verification

  1. STEP 1 · DECLARE

    Let n ∈ ℤ⁺ be an arbitrary positive integer. The three consecutive integers are n, n+1, and n+2, and their product is P(n) = n(n+1)(n+2).

  2. STEP 2 · PARITY

    In any two consecutive integers {n, n+1}, exactly one is even. Thus 2 | n(n+1), which implies 2 | P(n).

  3. STEP 3 · MODULO 3

    By division algorithm, n can be expressed as 3k, 3k+1, or 3k+2. If n = 3k, 3 | n. If n = 3k+1, n+2 = 3k+3 = 3(k+1), so 3 | (n+2). If n = 3k+2, n+1 = 3k+3 = 3(k+1), so 3 | (n+1). In every case, 3 | P(n).

  4. STEP 4 · COPRIME SYNTHESIS

    Since 2 | P(n) and 3 | P(n), and gcd(2, 3) = 1, it follows by Euclid's lemma that (2 × 3) | P(n), i.e., 6 | n(n+1)(n+2) for all n ∈ ℤ⁺. Q.E.D.

Stage 3 · Boundary Test & Perturbation

Boundary Test: Suppose the consecutive integers are allowed to be negative or include zero (e.g. n = -1, giving (-1)(0)(1) = 0). Does the divisibility by 6 property still hold for all n ∈ ℤ?

Prompt: Evaluate the limiting boundary case at n = 0, n = -1, and n = -2.

View Boundary Analysis

For n ∈ {-2, -1, 0}, the product contains 0 as a factor, yielding P(n) = 0. Since 0 = 6 × 0, 6 | 0 is true. For any negative integer n = -m (m ≥ 3), the product (-m)(-m+1)(-m+2) = -[m(m-1)(m-2)] is the negative of three positive consecutive integers, hence also divisible by 6. The divisibility invariant holds across all ℤ without exception.
