One consistent square-offset rule across pairs

A concept lesson about ordered pairs, a common offset, and a single exception. All examples are independently authored for this preview; none reproduces the original IMO question.

Begin with the mathematical relationship

How to check the same rule

y = x² + kk = y − x²A matching group must share the same residual k.

For each ordered pair (x, y), square the first coordinate, subtract it from the second, and compare the resulting values. Do not change the operation between pairs.

Why this is valid: Subtracting x² from both sides of y = x² + k gives k = y − x². Matching values establish consistency for the displayed examples, not a universal theorem.
Construction unit 01 · fixed orientation

Build the residual test

01

Declare the roles. Read the first coordinate as input x, and the second as output y.

02

Transform identically. Compute y − x² on every pair. A matching rule has the same k.

Stage 1 of 3
Quick check · why can a single pair mislead?
One pair can fit many possible formulas. To justify one common rule for the displayed observations, test it against each pair.
Mistake clinic · changing the offset to fit every pair
The claim is about one rule. Choosing a different k for each pair prevents any meaningful comparison. Write the residuals side by side and use the same formula throughout.
Mistake clinic · swapping x and y
In an ordered pair (x, y), x is the first coordinate and y the second. Swapping them tests a different relation, so the orientation must stay fixed.
Independent exit · authored, not Q003

Prove you can repeat the test

Given (2, 9), (3, 14), (5, 30), (6, 43), compute y − x² for all four pairs. Which one differs? Explain why checking only the first pair would be insufficient.

Model reasoning · authored exit

The residuals are 5, 5, 5, 7. Thus (6, 43) differs from the three observations fitting y = x² + 5. For x = 6, this rule predicts 41, not 43. One example alone does not establish a common pattern.

Lesson map

Concept → construction → independent exit

  1. Keep ordered pairs oriented.
  2. Transform each pair using the same expression.
  3. Find the common residual.
  4. Check the exceptional residual.
  5. Transfer the procedure to fresh values.
